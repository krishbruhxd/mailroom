Two return addresses. Nothing forces them to agree.

Paste the raw headers from a message you don't trust, or drop in the .eml file your mail client saved. Mailroom compares the address you see against the envelope the servers actually used, reads who vouched for the sender, and quotes every line it looked at — so you can check its work.

Runs in this tab. Nothing you paste or drop is uploaded.

Where to find the headers
Gmail, on the web
Open the message, click the three dots next to Reply, choose Show original, then Copy to clipboard.
Outlook on Windows
Open the message and go to File, then Properties. The full list is under Internet headers.
Apple Mail
With the message open, choose View, then Message, then Raw Source.
The whole message, as a file
Gmail: Show original, then Download original. Apple Mail: File then Save As. Thunderbird: Ctrl+S. The file ends in .eml — drop it anywhere on this card. Outlook's .msg files are a different format, so copy its headers instead.

      What this can't tell you

      • It reads headers, not content. Links, attachments and the body are never inspected.
      • Authentication that passes proves a domain sent the message — not that the domain is honest, or that the account behind it wasn't stolen.
      • Whoever assembled the message can write most of these lines by hand. A clean report is not a clean email.

      Mailroom runs entirely in your browser. No server, no account, no log of what you paste.
